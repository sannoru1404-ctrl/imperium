# Imperium

Мобильная стратегия в духе Total War: пошаговая кампания на карте + 3D-сражения в реальном времени.
Работает в браузере телефона (Three.js), в планах — Android-приложение через Capacitor.

## Структура

```
src/index.html        разметка и стили
src/js/main.js        точка входа, функции для кнопок
src/js/data.js        фракции, отряды, настройки ИИ (таблицы баланса)
src/js/mapdata.js     СГЕНЕРИРОВАН: география и регионы (не править руками)
src/js/state.js       состояние кампании, сохранения (3 слота + авто)
src/js/rng.js         генератор случайности с seed: вся логика игры детерминирована
src/js/map.js         карта кампании, найм, перемещение армий
src/js/turn.js        конец хода, ИИ фракций, авторасчёт боя
src/js/battle-sim.js  симуляция 3D-боя (без графики), ИИ боя
src/js/battle-3d.js   отрисовка боя (three.js), камера, управление
src/js/battle-hud.js  интерфейс боя
src/js/ui.js          окна, справка, сохранения, окно «Держава»
src/js/rules.js       экономика: доход, постройки, порядок и бунты, указы, технологии, воеводы
src/js/diplo.js       дипломатия: война, мир, торговля, союз; ИИ-решения
tests/                headless-тесты на Node
tools/geo-source.mjs  исходная география: побережья, реки, регионы (широта/долгота, владельцы 1100 г.)
tools/build-map.mjs   собирает mapdata.js: проекция, соседства (Delaunay), морские пути, территории
```

После правки `tools/geo-source.mjs`: `node tools/build-map.mjs` (нужен d3-delaunay).

Правило: игровая логика использует только `rand()` из `rng.js`, не `Math.random()`.
Тогда любую кампанию и любой бой можно воспроизвести по seed.

## Запуск

ES-модули не открываются напрямую из файла, нужен локальный сервер:

```sh
npm run serve        # затем http://localhost:8080
```

three.js грузится с cdnjs, нужен интернет.

## Тесты

```sh
npm test                          # всё: сохранения, 3D на заглушке, матрица боёв, 100 кампаний
CAMPAIGNS=20 RUNS=5 npm test      # быстрый прогон
```

`battle.test.js` печатает матрицу баланса: процент побед отряда-строки (атакует) против отряда-столбца.
`campaign.test.js` прогоняет кампании ботом и проверяет, что одинаковый seed даёт одинаковую игру.
