# Imperium

Мобильная стратегия в духе Total War: пошаговая кампания на карте + 3D-сражения в реальном времени.
Работает в браузере телефона (Three.js), в планах — Android-приложение через Capacitor.

## Структура

- `src/index.html` — вся игра (кампания, ИИ, 3D-бой). На этапе 0 будет разбита на модули.
- `tests/` — headless-тесты на Node: симуляция кампании, симуляция боя, отрисовка боя на заглушке three.js.

## Запуск

Открыть `src/index.html` в браузере (нужен интернет для three.js с cdnjs).

Тесты:

```sh
sh tests/run-all.sh
```
